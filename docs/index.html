Up and running in minutes

Three steps. That's it.

Download Melos

Grab the code from GitHub and install the dependencies. It takes a minute — no special hardware needed, just your streaming PC.

Connect to Your Channel

Set your Twitch channel name in a config file and authorize once through a browser. Melos joins your chat and waits for commands.

Let Your Viewers Play

Your audience types !sr song name in chat. Melos finds it, plays it through your stream. Done.

What viewers can do

Simple commands. Zero learning curve.

Music

!sr <song>Request a song
!randomPlay random tracks from your library
!voteVote to skip the current song
!nextSee what's up next
!whenEstimate when your song plays

Playlists

!create <name>Create a playlist
!add <list> <song>Add a song to it
!pump <list>Queue random songs from it

Stats

!statsBot activity overview
!top_songsMost requested songs
!top_usersMost active requesters

Admin (you)

!volume <0-100>Set playback volume
!skipSkip the current song
!blacklist <user>Block a user
!trust_channelApprove a YouTube channel
